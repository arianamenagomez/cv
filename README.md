# Anyel Mena · Portfolio

One-page portfolio of Anyel Ariana Mena Gómez, a Costa Rican designer and
illustrator who works with AI to help companies transform toward 2027.

**Live site:** https://arianamenagomez.github.io/cv/

## Highlights

- **AI layer:** a toggle that marks every piece where AI took part (photo, song,
  code, paper background). Hand-made work stays unmarked.
- **Visitor archetypes:** the visitor picks a profile and gets a suggested route.
- **Prompt anatomy:** the real Mureka prompt behind the song "Al despertar",
  with the method's rules highlighted on demand.
- **Accessible:** keyboard operable, screen-reader announcements, transcript for
  audio, reduced-motion support.

## Stack

Plain HTML, CSS and JavaScript. No build step.

```
index.html
css/styles.css
js/main.js
assets/img/    WebP images
assets/audio/  song
DESIGN.md      design system (Google DESIGN.md format)
```

Run locally by opening `index.html` in a browser.
